# Security Policy

## Reporting a Vulnerability

Report project-specific vulnerabilities through the affected repository's **Security** tab and follow that repository's `SECURITY.md` when present.

If the affected repository is unclear or the issue concerns this profile repository, use GitHub private vulnerability reporting here. Do not post credentials, personal data, exploit details, or other sensitive evidence in a public issue.

## Scope

This repository contains profile documentation rather than a deployed application. Supported versions and response expectations are defined by each affected project.
